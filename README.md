# DocuMind

A context-aware semantic search engine. Upload a PDF or TXT file and search it by meaning.

Stack: Streamlit, sentence-transformers (all-MiniLM-L6-v2), FAISS, PyPDF2.

## Run locally

    pip install -r requirements.txt
    streamlit run app.py
